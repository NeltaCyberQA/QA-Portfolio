# REST API Testing Project — JSONPlaceholder

## Project Overview

This project demonstrates hands-on REST API testing using Postman and the JSONPlaceholder API.

The project covers CRUD operations, positive and negative testing, HTTP status code validation, JSON response validation, and automated assertions.

A Postman collection was created to execute the API test suite as a functional regression run.

## Testing Scope

- GET — Retrieve a valid user
- GET — Validate behavior for a nonexistent user
- POST — Create a new resource
- PATCH — Update an existing resource
- DELETE — Delete an existing resource
- Positive and negative API testing
- HTTP status code validation
- JSON response body validation
- Automated Postman assertions
- Collection-level regression execution
